# 🥛 Milk Store

A responsive and user-friendly Milk Store website built using **HTML, CSS, and JavaScript**.  
This project demonstrates a basic eCommerce layout with interactive features and modern UI.


## 🚀 Live Demo

👉 **Live Preview:** https://milk-store1.netlify.app/

## 🛠️ Technologies Used

- **HTML5** – Structure & Content  
- **CSS3** – Styling & Layout  
- **JavaScript** – Add to Cart & UI Interactions

## 📌 Features

- 🥛 Clean product display  
- 🛒 Cart functionality using JavaScript  
- 📱 Fully responsive for mobile & desktop  
- 🎨 Stylish UI design  
- 💡 Simple yet interactive shopping experience

---
🎯 Project Purpose

This project was created to improve front-end development 
skills and practice real-world eCommerce layout design 
using pure HTML, CSS, and JavaScript without frameworks.
